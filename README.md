## Engenharia e Desenvolvimento com Agentes de IA

O desenvolvimento deste projeto é potencializado por agentes de IA executados via **Google Antigravity CLI** (`agy`), operando sob uma camada rigorosa de governança de software, Test-Driven Development (TDD) e auditoria contínua de segurança.

Nossa infraestrutura agentica integra três referências do ecossistema de agentes de código:
* 🦸 **[obra/superpowers](https://github.com/obra/superpowers)**: Metodologia de desenvolvimento orientada a especificações, TDD estrito e orquestração de subagentes.
* 🎯 **[mattpocock/skills](https://github.com/mattpocock/skills)**: Alinhamento de requisitos por entrevista (`grill-with-docs`), Linguagem Ubíqua ([CONTEXT.md](CONTEXT.md)) e Registros de Decisões Arquiteturais ([docs/adr/](docs/adr/)).
* 🛡️ **[affaan-m/ECC](https://github.com/affaan-m/ECC)**: Diretrizes técnicas de stack (React Native/Expo, Prisma ORM) e padrões de segurança do AgentShield contra vazamento de credenciais.

Consulte o **[Guia de Desenvolvimento com IA](docs/desenvolvimento-com-ia.md)** para instruções de onboarding e uso dos subagentes.
