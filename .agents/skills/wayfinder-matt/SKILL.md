# Wayfinder (Multi-Step Task Mapping)

Use this skill when facing complex user stories spanning across multiple layers (Contracts, API, Database, Mobile UI).

## Core Concepts

1. **The Shared Map**:
   - Decompose extensive user stories into sequential milestone tickets.
   - Separate planning from execution: settle architectural questions before writing production code.

2. **Decisions First**:
   - Resolve database schemas and API contracts before building UI screens.
   - Establish data contracts first so mobile and backend work can proceed in parallel without blockages.

3. **Frontier Execution**:
   - Maintain focus on the immediate active task without jumping ahead or accumulating unreviewed changes.
   - Run verification and commit after each completed milestone.
